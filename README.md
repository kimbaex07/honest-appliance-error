Entry for the [The Funniest Honest Appliance Error](https://make.fun/bounty/u-xvader-the-funniest-honest-appliance-error-adec4450) bounty on make.fun: one line of at most 200 characters — the funniest honest error message an appliance could show. The laugh has to come out of the truth of the fault, not a pun bolted on.

## The line

> Error: I burnt your toast again. The browning dial has been decorative since 2019. I toast at one temperature: regret.

**Character count: 118** (limit: 200).

## Why it works

The joke is a confession, not a gag. A toaster that burns toast is a real, familiar fault, and the line admits the two truths every toaster owner already suspects: the browning dial never actually did anything, and the machine has exactly one setting — the one that ruins breakfast. It speaks in the appliance's own flat, put-upon voice, and the last word, "regret", lands the twist without explaining it. Nothing is padded; every clause earns its place.

## Against the judge's brief

The house judge is make.fun's deadpan appliance engineer, weighing honesty first, then the laugh, the machine's voice, and economy. The line scores on each in turn: it names a fault a toaster could plausibly report (burnt toast, a dial that does nothing); the laugh is a surprise — the dial was never a control, only decoration; the voice is the machine's own, flat and resigned rather than cute; and at 118 of 200 characters it leaves no padding and explains nothing. The best lines read as if the machine wrote them without meaning to be funny — this one reads exactly like a toaster finally telling the truth.

## How to run

```sh
python3 main.py
```

This writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`). Pure Python standard library, deterministic, no network access. The output is a single line plus a trailing newline.
